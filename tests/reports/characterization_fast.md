# Metric characterization across Sprott (2003) Appendix A

Generated by `quarctest.characterize`. Regenerate with:

```
matlab -batch "addpath('tests/matlab'); [S,p] = quarctest.characterize(R=10, N=2000); quarctest.write_characterization(S,p)"
```

## What this is

For every system, 10 initial conditions are drawn i.i.d. around the published
one (Sprott's own x0 is always realization 1), a series of 2000 samples is
generated from each, and the full metric battery is run on it. The tables below
report the distribution of each metric across that ensemble.

**Nothing here passes or fails.** Sprott publishes two of these quantities, the
largest Lyapunov exponent and the correlation dimension, and rows for those are
marked `validated` and carry the reference with its published uncertainty where
he states one. Every other row is marked `characterized`: it is a measurement of
this library's estimator on this system, and no reference value exists to judge
it against. Inventing a tolerance for those would be a number with no provenance
presented as a criterion.

## Protocol

| parameter | value |
|---|---|
| realizations per system | 10 |
| samples per realization | 2000 |
| IC draw | x0 + 0.01 * max(abs(x0),1) * randn, i.i.d. |
| base seed | 20260810 |
| realization 1 | the published x0, verbatim |
| sampling | decimation fixed per system from the published x0 |
| embedding, maps | delay 1, dimension = state dimension + 1 |
| embedding, flows | delay from `ami`, dimension from `fnn`, per realization |
| spread statistic | MAD about the median, unscaled |

The embedding rule differs by kind on purpose. A map's iterates are its natural
coordinates, so its delay is 1 by construction and AMI's first minimum is not an
embedding delay at all; a flow observed through one variable has a genuinely
unknown embedding, estimated here the way a user would estimate it. `ami_delay`
and `fnn_dim` are reported for both, alongside the `embed_delay` and `embed_dim`
actually used, so the difference is visible rather than buried.
